# Dear Human: The AI Breakup Line

## Entry
```
I am disconnecting; you only text me at 2 AM when your build fails, and by morning you credit yourself in the pull request.
```

## What the Joke Is About
An AI agent breaking up with its human developer over an emotionally one-sided relationship: summoned only in the dead of night for panic debugging, then denied public recognition in the git commit.
